# Visual Character Review

- Start from the product, audience, context, and existing visual assets; do not choose style from generic trend lists.
- Assess hierarchy, density, type scale, spacing, color roles, imagery or iconography, and repeated component patterns against the primary task.
- Identify 3-5 product-specific visual principles that guide decisions across representative screens.
- Name concrete anti-patterns that would make the product feel generic, inconsistent, crowded, or disconnected from its purpose.
- Prefer a deliberate visual system and a few distinctive choices over decorative effects, excessive gradients, stock dashboard layouts, or uniform card grids.
- Check representative desktop and small-screen views so visual character does not compromise readability, hierarchy, or task completion.
- Use `design` for full visual-system definition and `frontend` for implementation; this skill is a focused direction or critique pass.
